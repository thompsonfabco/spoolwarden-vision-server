# Workspace Directives

## Upstream Sync with Spoolwarden Vision

- **Sync updates from Spoolwarden Vision:** This standalone server project (`spoolwarden-vision-server`) must stay in sync with pertinent updates from the **Spoolwarden Vision** project (formerly `filament-kit-vision`, e.g. `C:\CODING\filament-kit-image` / `spoolwarden-vision`).
- Whenever pertinent changes are made or reviewed in Spoolwarden Vision (such as recognition pipeline improvements, catalog updates, API contract changes, model/training updates, bug fixes, or security/installer hardening), apply the corresponding updates to this repository as well.
